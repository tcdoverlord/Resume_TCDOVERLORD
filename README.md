## 🚀 Selected Projects

### IP to Binary Converter

Browser-based IPv4 conversion utility that validates addresses and converts each octet to 8-bit binary with copy controls.

**Technologies:** HTML5, CSS3, JavaScript

**Repository:**  
https://github.com/tcdoverlord/IP-to-Binary-Converter

### CIDR Block IP Calculator

IPv4 CIDR calculator that displays total IP addresses, reserved addresses, usable addresses, and the underlying calculation.

**Technologies:** HTML5, CSS3, JavaScript

**Repository:**  
https://github.com/tcdoverlord/CIDR-Block-IP-Calculator

### 256-Bit Password Generator

Browser-based password generation utility featuring cryptographic randomness, 32-character passwords, section-based controls, copying, and offline operation.

**Technologies:** HTML5, CSS3, JavaScript, Web Crypto API

**Repository:**  
https://github.com/tcdoverlord/256-Bit-Password-Generator

### Windows Bluetooth & Phone Link Doctor

PowerShell troubleshooting utility designed to diagnose and repair Windows Bluetooth, audio, microphone, and Phone Link issues.

### Hyper-V Backup Bootstrap

PowerShell-based backup and recovery workflow for Hyper-V environments.

### SafeUSB Eject

PowerShell utility for safely ejecting USB storage devices on Windows.

### OBS Safe Launch Utility

PowerShell-based utility for launching OBS with a security-conscious workflow.
